# Polybius Workshop

A self-contained study site for working from low-intermediate Ancient Greek up to reading Polybius.

- **Plan**: a forty-week, four-phase reading and composition plan, with milestones.
- **Vocabulary**: spaced-repetition flashcards in Polybian decks (historiography, army, state, connectives, principal parts).
- **Parsing**: tap-to-parse drill on forms Polybius uses.
- **Syntax**: identify constructions in Polybian sentences.
- **Composition**: English → Greek with models; Beta Code typing supported.
- **Worksheets**: printable sheets with answer keys (open the page in a desktop browser and print).

Everything is in `index.html`; there is no build step. Progress is stored in the browser's localStorage, per device.
